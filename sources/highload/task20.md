# Task 20: Maximum Square

**Source:** https://highload.fun/tasks/20

## Description

Given a matrix of 10000x10000 uint8 elements with values 0 and 1 in STDIN.

Find and output the value of the side of the maximum square of 1's with side n, where n > 1.

## Input

- Binary data via STDIN
- 10000x10000 matrix of uint8 elements
- Each element is either 0 or 1

## Output

- Print the side length of the largest square sub-matrix consisting entirely of 1's to STDOUT
- The side must be greater than 1

## Constraints

- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
