# Task 18: Matrix Multiplication

**Source:** https://highload.fun/tasks/18

## Description

Two square N by N matrices in row-major order are encoded back-to-back. The size of N is fixed to 2000.

Perform matrix multiplication on these two matrices and output the resulting square matrix.

## Input

- Binary data via STDIN
- Two 2000x2000 matrices encoded in row-major order, back-to-back
- Element type: likely int32 or float (exact type from platform)

## Output

- The resulting 2000x2000 matrix from multiplying the two input matrices, in row-major order to STDOUT

## Constraints

- N = 2000 (fixed)
- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
