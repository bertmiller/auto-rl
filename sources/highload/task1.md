# Task 1: Sum of Numbers (Parse Integers)

**Source:** https://highload.fun/tasks/1

## Description

You receive a data stream of numbers in string representation via STDIN. Each line contains one number in the interval [0; 2147483647].

Try to find the sum of these numbers for the shortest time. In case of an integer overflow, just ignore it.

## Input

- Numbers as ASCII text, one per line, via STDIN
- Each number is in the range [0; 2,147,483,647] (uint32 range)
- Approximately 50,000,000 numbers

## Output

- Print the sum to STDOUT

## Constraints

- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
