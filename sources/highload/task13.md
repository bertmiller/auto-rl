# Task 13: Count uint8

**Source:** https://highload.fun/tasks/13

## Description

You have a data stream of uint8 numbers in binary representation sent to STDIN.

Try to find the count of elements with the value equal to 127 for the shortest time.

## Input

- Binary data via STDIN
- uint8 numbers (1 byte each)
- Numbers quantity: 250,000,000

## Output

- Print the count of elements equal to 127 to STDOUT

## Constraints

- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
