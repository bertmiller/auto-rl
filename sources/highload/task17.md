# Task 17: MD5

**Source:** https://highload.fun/tasks/17

## Description

Try to find the MD5 sum of the input data for the shortest time and print it in HEX representation.

3 CPU kernels are available.

## Input

- Binary data via STDIN
- File size: 250,000,000 bytes

## Output

- Print the MD5 hash in hexadecimal representation to STDOUT

## Constraints

- 3 CPU kernels available
- Score depends on wall time (not CPU time)
- Languages: C, C++, Go, Rust
