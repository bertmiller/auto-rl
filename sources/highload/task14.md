# Task 14: Blue from RGBA

**Source:** https://highload.fun/tasks/14

## Description

The data is a set of pixels in RGBA format (each pixel is presented by 4 bytes). You need to send only the Blue component of each pixel to STDOUT.

## Input

- Binary data via STDIN
- Pixels in RGBA format (4 bytes per pixel: R, G, B, A)
- Number of pixels: 125,000,000

## Output

- Write only the Blue component (3rd byte of each pixel) to STDOUT as binary data

## Constraints

- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
