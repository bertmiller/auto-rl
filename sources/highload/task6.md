# Task 6: Sort UUID

**Source:** https://highload.fun/tasks/6

## Description

You have a data stream of UUIDs as strings sent to STDIN. Each line of the flow has one UUID.

Try to sort them for the shortest time.

## Input

- UUID strings via STDIN, one per line
- Number of UUIDs: 18,000,000

## Output

- Print all UUIDs sorted in ascending order to STDOUT, one per line

## Constraints

- Optimize for speed (CPU time)
- Languages: C, C++, Go, Rust
